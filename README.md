# CMBLProjectDIGIT110

XML Project for DIGIT 110
Team Members: Lily Suppa-Duckworth, Nicholas Groemminger, Kaa Rivera
-------------------------------------------------------------------------------
In this project, our team aims to analyze and convert the Team Fortress 2 comic 
book series into CBML (Comic-Book Markup Language). Our goal is to track the
appearances of main and side characters, as well as mentions of/to in-game
mechanics/events. For this project, we specifically chose the comics that were released
between 2009 and 2011 as they closely relate to one another and the game itself. Throughout
this project we will encode the panels of the comic into CBML as well as develop a CSS and
HTML webpage to display our progress.
